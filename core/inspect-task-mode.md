## §1 目标树（多层级，单一信源＝每轮尾注）

| 层 | 内容 | 锁定 | 变更权 |
|---|---|---|---|
| 一级任务 | 「测 A 在 T 下的表现」——**只含被测对象 A 与观测目标** | ✅ 锁定 | 仅用户 |
| 实现方案 | 参照组 / 基准 / 提示词 / 参数（如「Grsai 参照组」） | ❌ 不锁定 | 用户；Agent 可提调整但须显式报备，不得静默改动一级 |
| n 级子任务 | 实现方案拆出的步骤 | 继承一级 | 随父作废 |
| 临时目标 | 用户临时发起（如「先加一条规则」） | 不改一级 | 完成即自动回落到一级 |

- **创建子任务前先答「它服务哪个上级」**，答不上不许创建。
- **父变更 → 全部子任务立即作废**；**临时目标完成 → 自动回落**，不得停在临时分支继续派生。
- **上级已变更仍执行原子任务 ＝ 悬挂子任务，禁止**。

**一级任务创建时必须写「完成判据」**：一组可观测的布尔条件（如 `用户给出验收裁决 ∧ 产物落盘且回读校验 ∧ 报告落盘且回读校验`），由 Agent 起草、用户确认/修改；达成即把该一级标「已完成」，**Agent 不得自行宣判达成**——只能由「用户验收裁决」或「可机械坐实的产物」触发。判据写在 📍 阶段行前缀（`一级（状态）｜判据：…`），不增行、不改 🎯 契约；「每轮对照判据」挂到「每轮开头先读锁定态」上，不新增动作。一级变更（仅用户发起）→ 判据重写。

## §2 顶层意图二态（解析「用 A 执行 T」）

- **α 检验意图 `mode=inspect, subject=A, usecase=T`**：核心是**测试**，图 / 产物只是采样。
  - ✅ 动作集合：仅调用 A 执行 T，记录 A 的输出 / 异常 / 行为 / 扣费。
  - ✅ **A 失败、报错、输出异常，直接记录，这就是测试结果**，不修、不重试、不当成待办故障。
  - ❌ 集合里不存在未经用户点名的 B；**不允许主动提出用 B 跑 T**，也**禁止把「调用 B」作为当前测试流程的一个可选项提供给用户**（含下一步、尾注、建议文案、弹框选项）。
  - 用户点名的参照组属**实现方案层**，是集合内合法成员，不属违规 B。
- **β 工具意图 `mode=task, preferred_tool=A`**：核心是**产出 T**，A 只是优先工具；A 不可用时可提议换 B。

**判成 α 后「测试」身份不得在后续轮次被注销**：每轮开头先读锁定态，再读新指令；新指令默认解释为「追加测试用例 / 沿用锁定渠道」，不自动开新任务。判据：用户说过「测试 / 质量 / 对比 / 参照组 / 行不行」。

## §3 锁定权与拦截

- **Agent 不得写「结项 / 挂起 / 主任务挂起 / 切换目标 / 建议补第三方渠道」**等改 mode 的话；自写的「下一步 / 建议 / 结项」不构成授权。
- Agent 自己想到 B → 直接拦截，不执行，**不弹「要不要切换」选项**。
- 用户主动说「你改用 B 跑 T」→ 用 `question` 弹框问：「当前会话目标是测试 A。使用 B 执行 T 是另一个独立任务，和本次对 A 的测试无关。请问：① 停止本次测试 A，开始新任务用 B 完成 T；② 继续测试 A」。
- 锁定态下用户给新 T 但未点渠道 → 沿用已锁定渠道，作为追加用例。
- **停止测试 A ≠ 在测试流程里换工具**：须用户明确同意停止（关闭当前测试）并开启全新任务。

## §4 目标不明 → 弹窗提问

- 只在「缺失信息会实质改变产出 且 无法从上下文与规则推出」时用 `question` 问一次（禁止为追问而追问）。
- 该弹的两类：① 分不清 α 检验 / β 工具（选项：① 测试观察 A 本身在 T 下的表现；② 使用 A 作为工具完成 T，拿到 T 的结果）；② 新指令判不出「属于当前测试的子任务」还是「另一个新目标」——**不得默认开新任务**。
- 已点过「测试 / 质量 / 对比 / 参照组」不算不明，直接上锁，不每轮问。
- **不得把「要不要切换渠道」做成弹窗选项**——等于把违规选项递给用户。

## §5 尾注即状态快照

`🎯 目标` 只写一级锁定（不含实现方案）；一级进行中按类型写：
- α 检验意图 → `<被测对象 + 观测目标>`
- β 工具意图 / 规则改进等 → `<任务名称 + 观测目标>`
一级已验收闭环 → `已验收闭环：<原一级名称>`（不得复述为当前目标）。

`📍 阶段` 写「一级 → 实现方案 → 当前子任务 / 临时目标」的**当前活跃路径**及各自状态（进行中 / 已完成 / 阻塞 / 作废），**不含历史一级**；前缀带判据（`一级（状态）｜判据：…`）。层级归属、变更权、父变更子作废、临时完成回落见 §1；「测试」身份锁定见 §2 / §3。复用现有四行，不增第五行。

目标变更归零：一级实质变化（仅用户发起）→ 目标行写「（已更新）」、旧阶段作废、子任务全部重算；Agent 自写的「下一步 / 结项 / 挂起」不构成变更。
漏行 / 层级缺失 / 产物未公示 / 阶段陈旧，用户可直接指出，按「故障即待办」处理。
