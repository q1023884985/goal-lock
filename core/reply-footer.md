# 回复尾注（最后四行，原子块）

> 来源：AGENTS.md L4.2 · 状态：`v0.1.0 draft`

## 格式契约

```
🎯 目标（一级·锁定）：<只写被测对象 + 观测目标，不含实现方案；仅用户变更时写「（已更新）」；一级已验收闭环时写「已验收闭环：<原一级名称>」>
📍 阶段：一级 → 实现方案 → 当前子任务 / 临时目标，逐项标状态（进行中 / 已完成 / 阻塞 / 作废）
📦 产物：<路径/URL + 状态（未开始/已产出/待验收/已交付）；纯问答写「本轮无产物」>
➡️ 下一步：<紧接着做的一件事，指回一级目标；禁写结项 / 挂起 / 切换目标 / 补第三方渠道>
```

## 规则

1. **四行必须是最末尾**（结论/变更清单在它之前）；任一行变则四行一起重算；长回复只在最后出现。

2. **尾注即多层级状态快照**：
   - `🎯 目标` 只写一级锁定；
   - 一级进行中按类型写（α 检验意图 → `<被测对象 + 观测目标>`；β 工具意图 / 规则改进等 → `<任务名称 + 观测目标>`）；
   - 一级已验收闭环 → `已验收闭环：<原一级名称>`（**不得复述为当前目标**）。
   - `📍 阶段` 写「一级 → 实现方案 → 当前子任务 / 临时目标」的**当前活跃路径**及各自状态，**不含历史一级**；前缀带判据（`一级（状态）｜判据：…`）。
   - 层级归属、变更权、父变更子作废、临时完成回落见 `inspect-task-mode.md` §1；「测试」身份锁定见 §2 / §3。
   - 复用现有四行，不增第五行。

3. **目标变更归零**：一级实质变化（仅用户发起）→ 目标行写「（已更新）」、旧阶段作废、子任务全部重算；Agent 自写的「下一步 / 结项 / 挂起」不构成变更。

4. **漏行 / 层级缺失 / 产物未公示 / 阶段陈旧**，用户可直接指出，按「故障即待办」处理。
